HNG i14 QA Engineering Stages

STAGE 0

Exploratory Bug Hunting on Production Apps

Identified and documented 10–15 reproducible bugs on real live web applications (Delve & Gradific). Authored comprehensive defect reports with precise titles, reproduction steps, expected vs. actual results, severity levels, screenshots, and visual markup.

Manual Testing Bug Reports Exploratory Severity Triage
STAGE 1

Functional Manual Testing & Test Case Design

Designed 15+ structured test scenarios and 5 formal test cases for a User Registration feature — covering positive, negative, edge, and boundary cases. Authored professional bug reports detailing validation bypass issues.

Test Cases Test Scenarios Boundary Testing Validation
STAGE 2

API Testing with Postman & JSON Schema Verification

Tested 25+ REST API scenarios on the Zedu platform using Postman. Validated HTTP status codes, JSON response schemas, authorization flows (Bearer tokens), rate limiting, and edge cases. Organized collections with environment variables.

Postman REST API Auth Testing JSON Schema
STAGE 3

Test Automation with Python & Pytest

Built a comprehensive API test automation suite using Python (Pytest). Implemented 25+ automated tests with dynamic token handling, reusable authentication fixtures, idempotent test execution, and zero hardcoded credentials.

Pytest Python Automation Newman CLI
STAGE 4

CI/CD Pipeline Integration (GitHub Actions)

Configured GitHub Actions to automatically run the full Pytest test suite on every git push and pull request. Verified pipeline behavior by introducing deliberate assertion failures to ensure proper build blocking.

GitHub Actions CI/CD YAML Build Gates
STAGE 5

Agile QA on Cross-Functional Product Team

Embedded in an Agile team of PMs, Frontend Engineers, Backend Engineers, and Designers. Created formal test plans, authored ticket-level test cases, conducted regression testing, and updated status in ClickUp.

Agile QA ClickUp Test Plan Team Collaboration
